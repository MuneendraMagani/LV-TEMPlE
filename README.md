# 🕉️ LV Temple Display System

A beautiful digital display system for temple events and poojas, featuring:

- **TV Display Mode**: Large screen display with auto-rotating upcoming events
- **Admin Panel**: Secure interface for managing events and users
- **Real-time Updates**: Auto-refresh for live event information
- **Hindu Aesthetic**: Beautiful Om (ॐ) symbols and temple-themed design
- **Snowflake Database**: Persistent data storage

## Features

✅ Featured event card with sub-events
✅ Upcoming events carousel with auto-rotation
✅ Responsive design (TV, desktop, tablet, mobile)
✅ Admin authentication and user management
✅ Change password functionality
✅ Automatic event filtering (hides past events)
✅ Beautiful gradient backgrounds with animated Om symbols

## Access

- **TV Display**: `/` - Main display for temple screens
- **Admin Panel**: `/admin` - Event management interface

## Technology Stack

- **Backend**: Node.js
- **Frontend**: Vanilla JavaScript, HTML5, CSS3
- **Database**: Snowflake (with JSON fallback)
- **Authentication**: bcrypt password hashing
- **Deployment**: Docker on Hugging Face Spaces
